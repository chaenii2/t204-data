# T204 데일리 브리핑 · 공개 데이터

테헤란로 T204 전광판 브리핑 화면이 읽어 가는 공개 데이터입니다. 15분마다 자동 갱신됩니다.

- 데이터 파일: https://chaenii2.github.io/t204-data/feed.json
- 링크용 플레이어: https://chaenii2.github.io/t204-data/player/
- 연결 진단: https://chaenii2.github.io/t204-data/player/#diag

출처: 기상청 단기예보·초단기실황, 에어코리아(강남구), 한국수출입은행 매매기준율, OpenDART 증권신고서.
API 키는 저장소 Secrets에만 있고, 이 저장소의 파일에는 포함되지 않습니다.
